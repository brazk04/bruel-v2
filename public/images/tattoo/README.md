# Fotografias reais de tattoo

Coloque nesta pasta as fotografias aprovadas dos trabalhos do Bruel, por exemplo `tattoo-001.webp`, `tattoo-002.webp` e `tattoo-003.webp`.

Ao cadastrar cada trabalho em `src/data/tattoo-works.ts`, preencha `image` com `/images/tattoo/nome-do-arquivo.webp`, forneça um `alt` descritivo e confirme título, categoria, estilo, ano e localização. O componente já usa `next/image` com `sizes` responsivo e espaço reservado para evitar deslocamento de layout.

Os estudos visuais atuais são placeholders editoriais e não representam tattoos do artista.
